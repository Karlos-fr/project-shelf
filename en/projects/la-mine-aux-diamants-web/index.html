La Mine aux Diamants

The 1986 Thomson TO8 game, ported pixel-close to TypeScript and playable in the browser.

A modern port of La Mine aux Diamants, published by Infogrames in 1986 for the Thomson TO8. Graphics, levels, fonts and sounds were extracted or rebuilt from the original binaries and an analysis of the 6809 assembly. The gameplay is then reproduced tile by tile in a modern TypeScript architecture. Besides the TO8-faithful rendering, the project offers a true 3D diorama mode, a level editor, a level generator and a character editor.

About the project

A preservation project around a classic of 1980s French home computing. The goal is to play the game as it was, documenting every choice from the original sources, then give it modern tools. Rights to the original game remain with their respective owners.

Key features

  • Infogrames splash and animated title screen with its music
  • Original attract/demo mode with its decoded hidden level
  • Tile-based engine: rocks, diamonds, monsters, special creature, transformer block, gravity, explosions
  • Original levels decoded from the floppy disk
  • TO8 HUD: score, time, high score, gallery, goal
  • Options panel: zoom, stretch, density, smooth movement
  • Diorama TO8 mode in true 3D (Three.js), purely visual
  • Level showcase with animated previews
  • Built-in JSON level editor
  • Seeded procedural level generator
  • Free-color character editor

Current limitations

  • Timing is not yet perfectly matched to the TO8.
  • Some behaviors remain hypotheses until the assembly analysis settles them.
  • Level progression and unlocking are not wired in yet.
  • The level generator is still experimental.

Technologies

TypeScript · Vite · Canvas 2D · Three.js (WebGL) · Web Audio API · Node.js · GitHub Pages
