The 1997 racer Fun Tracks, rebuilt from its original code for modern PCs, Android and Linux.

Fun Tracks Recomp brings the 1997 arcade racer back to life. The game was decompiled into readable C, then rebuilt as a native program for today's systems. The original renderer still reproduces the 1997 picture exactly, frame for frame. A new 3D renderer adds widescreen, a smooth frame rate, modern lighting and an optional HD texture pack. It needs the original game files: CD, GOG or Steam.

About the project

Fun Tracks was a small 1997 racer full of character that only ran on old Windows. This project started as a decompilation, matched byte for byte against the original compiler, and grew into a full recompilation: the same game, playable again on today's hardware, with optional modern visuals.

Key features

  • Same game, same physics: rebuilt from the original code, deterministic down to the frame.
  • Original 1997 renderer, 1:1, or a modern 3D renderer (Vulkan, Direct3D 12).
  • Widescreen, high resolutions, smooth frame rate with interpolation.
  • Dynamic lighting, shadows, reflections, weather and time-of-day options.
  • Free HD texture pack covering all seven tracks.
  • Analog gamepad support, split screen for up to 6 players, network play.
  • Windows, Android and Linux, plus a test build for PortMaster handhelds.
  • Six languages.

Current limitations

  • Alpha builds.
  • The original game files are required.
  • Linux and handheld builds are still test builds.
  • Network play is experimental.
  • Devices without Vulkan only run the original renderer.

Technologies

C11 · CMake · SDL3 · WebGPU (wgpu-native) · Vulkan / Direct3D 12 · Android NDK / Gradle · Ogg Vorbis · Python · MSVC 4.2
